Appearance

A greeting, a colour and a corner. Custom styles, fonts, images and scripts are deliberately not offered: the widget runs on your visitors' machines, and what runs there is not something a settings page should be able to change.

Shown at the top of the chat before anybody types. It is plain text you wrote, shown as your words rather than as something the AI said. Up to {{ maxGreetingLength }} characters, and it may be left empty.

Used for the launcher, the header and the visitor's own messages. The text on top is chosen automatically so it stays readable.

Security

The chat runs in a frame served by OmniAI, so the site it is embedded in cannot read the conversation, cannot read the visitor's session, and cannot style or script anything inside it. Nothing about your workspace, your agent or your knowledge is sent to the page.

The widget does not use third-party cookies, so it keeps working in browsers that block them.

Removing a website takes effect at once — conversations already open on it stop being answered, because every message is checked against this list again rather than trusting the session that was opened earlier.

This list controls where the chat may be embedded. It is not a limit on how much anybody can send: the rate limits and abuse protection apply to every conversation regardless of which website it started on.
