What happens when you upload

  • The text is read out of the file and saved as a document you can edit like any other.
  • The file itself is not stored. It is read once, during the upload, and discarded — there is nothing to download afterwards, so keep your own copy.
  • Indexing is a separate step. The document arrives needing an index, and nothing is sent to the AI provider until you ask for it on the next screen.
  • Scanned PDFs are not supported. A PDF has to contain real text. Pages that are pictures of text need OCR, which this platform does not do yet.
  • Spreadsheets, presentations, images and archives are not supported. Save a spreadsheet as CSV if you need its contents here.
